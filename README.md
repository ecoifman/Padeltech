# PADELTECH ישראל

אתר המועדון **PADELTECH** — מקום שבאים אליו לשחק. המתחם הראשון בדרך.

PADELTECH זה לא המקום שבו שוכרים מגרש. זה המקום שבאים אליו לשחק.

האתר בעברית (RTL) כברירת מחדל בנ״`/he`. תרגום באנגלית בנ״`/en`.

אין כאן סניף פתוח, מחירון, או הזמנה חיה. כפתור ההזמנה שומר מקום ברשימה עד שמערכת ההזמנות תפורסם (`NEXT_PUBLIC_BOOKING_URL`).

## הרצה מקומית

```bash
npm install
cp .env.example .env.local
# set ADMIN_PASSWORD in .env.local to open /admin
npm run dev
```

האתר עולה בנ״[http://127.0.0.1:4321](http://127.0.0.1:4321) ומפנה לנ״`/he`.

```bash
npm run build
npm start
```

## עמודים

- `/he` — עמוד הבית: הירו, חוויה, מגרשים, הזמנה, אנשים, חברות, ציוד, המועדון
- `/he/book` — הזמנת מגרש (מגרש → שעה → תשלום → משחק)
- `/he/padel` — המשחק ודרכי הצטרפות
- `/he/clubs` — המועדון הראשון, בקרוב
- `/he/story` — הסיפור
- `/he/groups` — חברות וקבוצות
- `/he/partners` — בעלי נכסים ושותפים
- `/admin` — תיבת פניות, מאחורי סיסמת מנהל

צילומים ווידאו באתר הם הדמיות וסומנו כך. הם אינם סניף של PADELTECH.

בריף תמונות לכל פריים וגודל: [`docs/photo-brief.md`](docs/photo-brief.md).

## טפסים ושמירת נתונים

שלושה סוגי פניות נשמרים בקובץ מקומי `data/inquiries.json`:

1. התעניינות בפעילות
2. חברות וקבוצות
3. נכסים ושותפויות

הודעת הצלחה מוצגת רק אחרי שמירה בפועל. האתר **אינו שולח דוא״ל**.

## אזור ניהול

מוגדר רק אם `ADMIN_PASSWORD` קיים במשתני הסביבה.

בנ״`/admin` אפשר לסנן, לחפש, לעדכן סטטוס, להוסיף הערות ולייצא CSV.

## לפני השקה

- להגדיר `ADMIN_PASSWORD` (ו־`ADMIN_SECRET` נפרד, רצוי) בסביבת הייצור
- לחבר אחסון עמיד לפניות במקום קובץ מקומי, אם האתר רץ על מופע מתחלף
- לא לפרסם סניף בנ״`lib/clubs.ts` לפני שיש מידע מאושר
- כפתור הזמנת מגרש חי יעבוד כש־`NEXT_PUBLIC_BOOKING_URL` מוגדר
- להחליף הדמיות לפי הבריף בנ״`docs/photo-brief.md`
